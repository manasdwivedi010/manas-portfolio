# Manas Dwivedi | Developer Portfolio

A high-performance, minimalist developer portfolio styled after obsidian wireframes and grid telemetry aesthetics. Designed to showcase modern software engineering practices, certified cloud operations, and interactive tools.

## 🚀 Live Preview
- **URL**: [manas-portfolio.vercel.app](https://manas-portfolio.vercel.app)
- **Design Inspiration**: `manvsin.vercel.app` (Obsidian Wireframe / Telemetry Theme)

---

## 🛠️ Technical Arsenal
- **Languages**: Java, Python, C, SQL
- **Frontend**: JavaScript (ES6+), React.js, HTML5, CSS3, Bootstrap
- **Databases**: Oracle, MySQL, MongoDB
- **Developer Tools**: Git, Selenium, Cucumber, Jenkins, JMeter, Jira

---

## 📁 Projects Showcased
1. **FaceLogix (AI Face Recognition Attendance System)**: Real-time subject-wise logging system using Python, React, WebSockets, and MySQL.
2. **Research Buddy (AI Research Platform)**: Conversational research companion for parsing, summarizing, and cross-referencing academic papers.
3. **University Management System**: Java-based relational enterprise solution for managing course registration, grading, and schedules.
4. **Netflix Clone**: Pixel-perfect frontend replica of the Netflix homepage with dynamic visual hover rails.

---

## ⚙️ Interactive Features
- **Console Terminal Emulator (`>_`)**: A fully functional command line console to explore user profile, education, stats, and projects using text commands.
- **Connect Form integration**: Full-stack connection form hooked up to FormSubmit API to deliver messages straight to personal mail.
- **Embedded Resume Preview**: Custom modal viewing drawer featuring a detailed image preview and download links.
- **Responsive Theme Layout**: Custom CSS grid system optimized for both desktop viewports and mobile screens.

---

## 📂 Project Architecture
- `index.html`: Responsive DOM structure and semantic layout elements.
- `styles.css`: CSS Grid columns background, wireframe border layouts, and micro-animations.
- `script.js`: Terminal input command parser, modal toggles, and navigation handlers.
- `manas_dwivedi_resume.pdf`: Active resume download file.
